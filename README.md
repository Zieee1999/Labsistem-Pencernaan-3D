# Labsistem-Pencernaan-3D
Media pembelajaran interaktif berbasis 3D untuk mengenalkan sistem pencernaan manusia kepada siswa Sekolah Dasar. Dilengkapi eksplorasi organ, simulasi perjalanan makanan (Play Process), animasi proses pencernaan, dan kuis interaktif untuk menciptakan pengalaman belajar yang menarik, visual, dan edukatif.
